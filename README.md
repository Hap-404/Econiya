# Econiya static website

Open this folder in VS Code and serve it through a local web server.

## Run locally

```bash
python -m http.server 5500
```

Open `http://localhost:5500/`.

## Completed in this package

- Existing homepage retained.
- About Us page implemented from the supplied design.
- About assets added under `assets/images/about/`.
- About-specific styles added in `assets/css/about.css`.
- Navigation and shared footer retained.
- Back-to-home links on placeholder pages corrected.

The Products, Solutions, Insights and Contact pages remain placeholders until their designs are supplied.
